Gallery Timeline 方案

A/B/C/D 旧方向 + E/F/G/H 新方向（不占左侧轨道、让 timeline 元素承载真信息）。

A. 节点 + 连线

classical

经典 vertical timeline：左侧一条软线穿起每个 stack 的小节点，最新一项节点用主色。适合让用户感觉"批次是顺着时间发生的"，但占用 40px 左轨。

B. Sticky 日期分组

linear inbox

按天分组，分组 label 是 uppercase eyebrow + 一条 hairline；滚动时 day header 吸顶。Linear / Things 那种"明确日历"的节奏，最适合长历史。

C. 左侧 mono 时间戳

log / journal

像 git log / Things journal：左固定列 mono 时间，右侧 stack 内容。没有节点也没有连线，靠对齐表达 timeline，最节省视觉成本；跨日插入一条 hairline + label。

D. 卡片色条 + inline meta

notion subtle

最贴近你现在的 StackRow，改动最小：在卡片左缘加一条 2px 色条作为时间锚点（最新批次用 accent），头部把模型名 / 相对时间 / 绝对时间合并到一行。没有大轨道、不分组。

E. 大 mono 时间 + 跨日 hairline

terminal log

把 header 里的小字时间换成 18px mono 大时间戳，作为视觉锚；同日内 stack 之间无任何分隔，跨日时插一条 hairline + 日期 label。不占左侧任何宽度，时间承载"现在看的是哪个时刻"。

F. 间隔差 chip（commit 风格）

git log

stack 之间插入一条 hairline，中间夹一个 mono 小 chip 标 "+ 3h 24m"——你能直接读出"上一次距离这次隔了多久"。跨日时 chip 升级成日期 band。零左侧占用，分隔本身就是 timeline。

G. 模型色侧条（承载新鲜度 + 模型）

linear status

内嵌 3px 色条贴在卡片内左缘——色相 = 哪个模型，透明度 = 距今多新（今天 100% / 昨天 55% / 更久 32%）。一眼可读"批次属于哪个模型 + 大致新旧"，且不占任何额外宽度。

H. 极简：仅 hairline 分隔 + 居中相对时间

whisper

最克制的方案：stack 之间一条 hairline，居中一个 mono "3h" / "1d"，像 iMessage 时间分隔。stack 本身完全保持你现在的样子，零结构变更，只是把"间隔"语义化。
