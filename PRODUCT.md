# Product

## Register

product

## Users

Nano Banana Playground is for creators, developers, and model explorers who need a precise local workspace for image generation. They are usually comparing models, tuning prompts, attaching reference images, reviewing batches, or using the Agent panel to turn rough intent into executable image tasks.

## Product Purpose

The product provides a browser-first playground for Gemini and GPT image generation. It keeps API keys and history local, makes model capabilities and costs visible before generation, and helps users move between prompt drafting, reference management, generation, inspection, and export without account or server friction.

## Brand Personality

Precise, quiet, and controlled. The interface should feel like a serious creative tool: compact, legible, calm under complexity, and confident enough to let the generated images take visual priority.

## Anti-references

Avoid generic AI SaaS aesthetics: decorative gradients, glowing chrome, inflated hero patterns, and card grids that look produced from a template. Avoid low-contrast polish that makes the app feel fragile or inaccessible. Avoid playful visuals that weaken trust in a production-quality tool.

## Design Principles

- Make image work feel inspectable: model settings, costs, references, history, and metadata should be easy to verify.
- Keep the chrome quiet so generated images and prompt decisions stay central.
- Prefer familiar product affordances over novelty; this is a tool users return to, not a one-time showcase.
- Reveal complexity progressively, especially around settings, provider credentials, web tools, and Agent actions.
- Treat accessibility as part of polish: readable contrast, visible focus, motion restraint, and resilient states are non-negotiable.

## Accessibility & Inclusion

Target WCAG AA contrast for text and interactive states across light and dark themes. Preserve keyboard navigation, visible focus indicators, reduced-motion fallbacks, and touch-friendly targets on mobile. Do not rely on color alone for status or selection.
